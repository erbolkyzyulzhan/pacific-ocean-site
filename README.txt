ТЫНЫҚ МҰХИТЫ — оқу жобасы

Сайтта Тынық мұхитының тереңдік аймақтары, қонақтарға арналған сұрақ/дерек формасы және деректер базасын көру беті бар. Аймақтар, тұрғындар, фактілер, адамға арналған жағдайлар мен қонақ жазбалары SQLite базасында сақталады. База ocean.db файлы ретінде автоматты түрде жасалады.

Іске қосу:
1. Python 3 орнатылған компьютерде осы бумаға кіріңіз.
2. Терминалда орындаңыз: python server.py
3. Сервер көрсеткен мекенжайды браузерде ашыңыз.

Егер 8000-порт бұғатталған немесе бос болмаса, сервер басқа портты өзі таңдап, нақты мекенжайын көрсетеді.
Қонақтар сұрақ немесе дерек ұсынып, оны SQLite базасына жібере алады. Жаңа жазбаларды тек әкімші /feedback бетінен көре алады. Келген жазбалар жеке сақталады, ал «Жариялау» батырмасын басқанда ғана негізгі сайтта көрсетіледі.
Сайтты іске қосқаннан кейін консольдегі «Пароль для просмотра» жолынан жеке бөлімнің құпиясөзін алыңыз. Құпиясөз admin_password.txt файлында да сақталады; сайт ол файлды браузерден ашуға рұқсат бермейді.
Жеке бөлімге сайттың жоғарғы жағындағы «Келген сұрақтар» батырмасы немесе /feedback мекенжайы арқылы кіріңіз. Жаңа жазбалар ашық тұрған жеке бөлімде әр 10 секунд сайын жаңарады.
Деректер API: /api/zones, /api/species және (тек кірген әкімшіге) /api/database
