# Pacific Ocean — мұхит тереңдігіне саяхат

Тынық мұхитының бес тереңдік аймағы туралы интерактивті оқу сайты. Жоба қазақ тілінде жасалған.

## Мүмкіндіктері

- Бір ұзын бетте мұхиттың бес аймағы бойынша төмен қарай саяхат.
- Әр аймақтың фактілері, тіршілік иелері және адамға арналған жағдайлар туралы қалқымалы терезе.
- Қонақтар сұрақ немесе дерек жібере алады.
- Жазбалар SQLite базасында сақталады. Әкімші оларды құпиясөзбен қорғалған `/feedback` бетінен қарап, жариялай алады.

## Жергілікті іске қосу

Python 3 қажет. Осы бумада терминал ашып, орындаңыз:

```powershell
python server.py
```

Терминалда көрсетілген мекенжайды браузерден ашыңыз. Әкімші құпиясөзі де іске қосу терезесінде көрсетіледі. SQLite базасы мен әкімші құпиясөзі жергілікті түрде сақталады және Git-ке жүктелмейді.

## Онлайн жариялау туралы

Бұл жоба Python сервері мен SQLite деректер базасын пайдаланады. GitHub Pages тек статикалық сайттарды жариялайды және Python серверін іске қоспайды, сондықтан GitHub-тағы код репозиторийі мен онлайн жұмыс істейтін сайт — екі бөлек қадам. Қонақтардың формасы мен жеке әкімші бөлімі жұмыс істеуі үшін Python серверін іске қоса алатын хостинг қажет.

### PythonAnywhere-ге жариялау

`flask_app.py` — хостингке арналған WSGI кіру нүктесі. PythonAnywhere-де Flask қосымшасын жасап, осы жобаны аккаунттың жеке файлдар бумасына жүктеңіз. Web бетіндегі WSGI файлына жоба бумасының жолын `sys.path` ішіне қосып, `from flask_app import app as application` жолын енгізіңіз. Сайтты қайта жүктегенде SQLite базасы мен әкімші құпиясөзі жоба бумасында жасалады; `admin_password.txt` файлын PythonAnywhere файлдар бөлімінен ғана оқуға болады.

PythonAnywhere-дің тегін жоспары уақытша демонстрацияға арналған: 2026 жылғы жоспар бойынша веб-қосымша бір айдан кейін аяқталады. Ұзақ уақыт онлайн ұстау үшін хостинг жоспарын тексеріңіз.
